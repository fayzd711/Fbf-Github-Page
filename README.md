# Fbf GitHub Page

A static GitHub Pages starter site. It is intentionally plain HTML and CSS so it can be hosted directly from a repository without a build step.

## Files

- `index.html` is the page content.
- `styles.css` is the visual design.
- `assets/hero.png` is the generated hero image.
- `.nojekyll` tells GitHub Pages to serve the files as-is.

## Publish on GitHub Pages

1. Create a repository on GitHub, or use an existing repository.
2. Add these files to the repository root and push them to GitHub.
3. In GitHub, open the repository settings.
4. Go to **Pages**.
5. Set the source to deploy from a branch.
6. Choose the default branch and the root folder.

For a user site, name the repository `<your-github-username>.github.io`. For a project site, any repository name works and GitHub will publish it under that project URL.
